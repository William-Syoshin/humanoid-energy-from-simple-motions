Energy prediction errors over 2-, 5-, and 10-second integration windows (2026-11-01)

Scope: the existing nine unseen motions, using saved R0-R3 predictions at 10 Hz.
No refitting, prediction clipping, or additional smoothing is applied.
Complete non-overlapping windows start at each original evaluation interval's beginning. Trapezoidal integration uses linear interpolation at window boundaries. Settling is retained where included in the original interval; incomplete tails are excluded.
Window error = 100 * abs(predicted_J - measured_J) / measured_J.
Errors are averaged within each motion, then equally across nine motions. Windows are not independent experimental repetitions.

Interpretation:
- R3 has the lowest mean at each length, but does not improve every motion or window.
- R3's error is 2.59% for complete movements versus 5.29% for 2 s windows. Over- and underprediction can cancel in a full integral.
- Supine get-up: R3 full-movement error 0.90%; mean 2 s error 10.54%; maximum 36.32%. Full energy error does not guarantee peak or local accuracy.
- R2/R3 are worse than R0 for Cheer. R1 has lower error than R2/R3 for Crawl. The aggregate ranking is not universal.
- Different window lengths exclude different tails. Differences cannot be attributed solely to integration duration.
- Each motion has one recording. This retrospective analysis was designed after examining the existing tests and is not independent confirmation.
