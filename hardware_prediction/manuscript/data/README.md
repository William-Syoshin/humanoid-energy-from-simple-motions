# Historical single-execution analysis and original training subsets

The CSV files and prediction traces in this directory describe the original nine-recording test set, including Supine get-up. They are retained as provenance for the original public commit. They are not the current primary test data.

Use [repeated_evaluation_20261109](../../repeated_evaluation_20261109/README.md) for the current 45-recording test set, including Bow, and current results. Default root reproduction commands use that new set. Original training subset identities under `transfer_audit_20260928/` are still used for the current exploratory coverage comparison.
