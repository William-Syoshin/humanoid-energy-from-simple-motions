# Figures supplied with the paper

The ten `fig01_...pdf` through `fig10_...pdf` files are the paper figures. Their contents and numbering are unchanged. See the [figure and table map](../docs/FIGURE_MAP.md) for each figure's data and verification action.

From the repository root, `python tools/reproduce.py figures` rebuilds numerical panels for Figures 4, 5, 6, 7, and 10 into a new `generated/` folder. It does not regenerate photographs or replace the supplied publication artwork. The [archived builder scripts](archived_build_scripts/) are provenance; some refer to historical paths and are not the portable entry point.
