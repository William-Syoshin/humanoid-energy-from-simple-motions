# Original Windows handoff: English reading guide

See [README.md](README.md) for the English software/protocol description. This directory also preserves the original Japanese handoff text exactly as received, because it is covered by the returned archive's SHA-256 manifest.

The original package proposed 12 or 72 trials. The completed study instead contains 24 single replays, with fixed order and provisional mapping; the [returned-results guide](../README.md) is authoritative for those observations. Initial software validation must not be confused with hardware validation. No fresh acquisition is needed to reproduce the analyses.

For new acquisition, establish the actual machine's servo mapping, calibration, serial ports and timing, check the selected plan and start pose, and perform dry runs before explicit hardware execution. Preserve every attempt. Independent displacement/timing measurements would be needed for equal-distance energy claims. See the full English guide for command semantics, logging windows, final-target behavior and analysis.
